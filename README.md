 Gastronomicomicon|
 
餮魔典 (Gastronomicon) 是一款为 Minecraft 1.20.1 打造的史诗级食物模组，添加了10种来自禁忌 cookbook 的超凡料理。
翻开魔典，开始禁忌盛宴！

⚠️ 项目状态：停止维护
本模组已不再开发，不推出新功能或修复问题。
